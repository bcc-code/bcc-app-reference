# User manual

For end users and administrators of the application. The template ships without content, because the Notes sample is not a
product. When the application has real users, write the manual here, following [Diátaxis](https://diataxis.fr) (standard 23,
rule 11). One folder per quadrant, created when its first page is written:

| Folder | Purpose | Style |
|---|---|---|
| `tutorials/` | Learning: a guided first success for a new user | Step by step, one path, no choices |
| `how-to/` | Doing: how to reach a goal the reader already has | Numbered steps for one task |
| `reference/` | Looking up: roles, fields, limits, statuses | Complete and factual, no instructions |
| `explanation/` | Understanding: why the application works as it does | Prose, no step lists |

Keep instructions out of reference and explanation pages, and use the labels the user interface shows. Mark pages drafted with AI
as such until a person has checked them against the application (rule 15).

Developer how-tos are in [`../development.md`](../development.md).
